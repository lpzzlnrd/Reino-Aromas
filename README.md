# Reino-Aromas

Repositorio para desarrollo de CRM para Reino Aromas.

## Protección de rama `main`

La rama `main` está protegida. **No se permiten pushes directos**; todos los cambios deben realizarse a través de un **Pull Request** con al menos 1 aprobación.

Consulta la [Guía de Contribución](CONTRIBUTING.md) para conocer el flujo de trabajo completo y los pasos para aplicar/actualizar las reglas de protección.
